# Nota Kilat GKT

Nota ulang kaji saat akhir SPM untuk **Grafik Komunikasi Teknikal Tingkatan 4 dan 5** (16 bab).
Disediakan oleh **Cikgu Rabbani, SMK Dato' Undang Musa Al-Haj, Jelebu**.

## Kandungan

| Fail | Fungsi |
|---|---|
| `index.html` | Seluruh modul (nota, rajah, kuiz, carian). |
| `icon-180.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `icon-32.png` | Ikon shortcut telefon dan tab pelayar. |
| `manifest.webmanifest` | Nama dan ikon apabila ditambah ke skrin utama. |
| `sw.js` | Membolehkan nota dibuka tanpa Internet selepas kali pertama. |

Tiada folder. Muat naik **semua fail** ke repositori yang sama.

## Terbit di GitHub Pages

1. Cipta repositori baharu (contoh: `nota-gkt`).
2. **Add file → Upload files**, pilih semua fail di atas, kemudian **Commit changes**.
3. **Settings → Pages**: pada Branch pilih `main` dan `/ (root)`, kemudian **Save**.
4. Alamatnya: `https://NAMA-AKAUN.github.io/nota-gkt/`

## Shortcut di telefon

- **iPhone (Safari):** buka alamat itu → butang Kongsi → **Add to Home Screen**.
- **Android (Chrome):** buka alamat itu → menu tiga titik → **Add to Home screen**.
